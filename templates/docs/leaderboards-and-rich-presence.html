{% include "components/section-heading.html" with title=_("Leaderboards") %}
  • {% trans "A leaderboard starts when its start condition becomes true, is cancelled by its cancel condition and submits the value it tracks when its submit condition becomes true. The emulator shows the running value while it is active." %}
  • {% trans "Leaderboards only run in hardcore mode: in softcore the emulator neither tracks nor submits them." %}
  • {% trans "Each player keeps one entry, their best: the highest score, or the lowest value when lower is better, as with times. A worse attempt does not replace it." %}
  • {% trans "The game page's Leaderboards tab lists them; each has its own page with every rank." %}
  • {% trans "Staff add new leaderboards. To propose one, describe it in the game page's comments." %}

{% trans "A leaderboard is written as four condition strings, the same syntax as achievements:" %}

STA:…::CAN:…::SUB:…::VAL:…

{% include "components/section-heading.html" with title=_("Rich presence") %}
  • {% trans "While you play, the emulator reads a few memory values and sends a short line about what you are doing, such as the level you are in. The site shows it as playing now on your profile and on the home page." %}
  • {% trans "The emulator sends it about every two minutes, and only fetches the script when a game loads, so a change shows after the game is opened again." %}
  • {% trans "Each game has one script, which staff maintain. Without one, the site only shows which game you are playing." %}

{% trans "A script defines formats and lookups, then the line to display, reading memory with macros:" %}

Format:Val
FormatType=VALUE

Display:
Stage @Val(0xH619c5)
