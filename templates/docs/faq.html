{% include "components/section-heading.html" with title=_("What is a subset?") %}

{% trans "A game's core set is its normal 100%: what the game itself asks of you to finish it. Challenges that go beyond it, such as a deathless run, a no-hit boss or a long grind, live in subsets, so you only play them if you want to. The game page lists each subset below the core set." %}

{% include "components/section-heading.html" with title=_("How do I play a subset?") %}

{% trans "Every subset starts off. Log in, open the game page and turn on Play this subset in the subset's section; it applies the next time you open the game in the emulator. Turn it off the same way. A specialty or exclusive subset has no switch: it plays when you load the disc it is made for." %}

{% include "components/section-heading.html" with title=_("What counts for the platinum?") accent="state-platinum" %}

{% trans "Only the core set: unlock every official achievement of a game's core set in hardcore and the game is platinum. A subset completed in hardcore earns its own Completed seal instead. Points from every set count on your profile and in the ranking." %}

{% include "components/section-heading.html" with title=_("Why did an achievement not unlock?") %}
  • {% trans "The emulator did not recognise the disc, so it loaded no achievements for it. Check that your disc is in the list above." %}
  • {% blocktrans trimmed %}The emulator is not connected to this site: check the Host in DuckStation's settings.ini and that you are logged in, as the getting started guide shows.{% endblocktrans %}
  • {% trans "It belongs to a bonus or challenge subset you have not turned on, or you turned it on while the game was open: close the game and open it again." %}
  • {% trans "It is unofficial: the emulator lists it only with Test Unofficial Achievements on, and an unofficial achievement is never recorded or worth points." %}
  • {% trans "Its condition was already true when the game loaded, for example from a save state made after the moment: the emulator holds it back until the condition turns false and true again." %}
  • {% trans "It changed after you opened the game: the emulator only fetches achievements when a game loads, so close the game and open it again." %}
  • {% trans "It has a bug. Tell its author in the comments on the achievement's page." %}
{% include "components/section-heading.html" with title=_("Hardcore or softcore?") accent="state-hardcore" %}

{% trans "Both are worth the same points, and the site shows each total apart. Hardcore turns off save states, cheats and rewind; an achievement unlocked in hardcore also counts in softcore. Leaderboards only run in hardcore." %}

{% include "components/section-heading.html" with title=_("Do I need a RetroAchievements account?") %}

{% trans "No. RetroPlatinas speaks the same protocol as RetroAchievements, so the emulator works unchanged, but accounts, achievements and progress are separate: log in with your RetroPlatinas account." %}
