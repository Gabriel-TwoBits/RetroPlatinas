{% include "components/section-heading.html" with title=_("Condition syntax") %}

{% trans "A condition compares memory values. These are the pieces most conditions use:" %}

0xH1234
{% trans "The 8-bit value at address 0x1234. 0x is 16-bit, 0xW 24-bit and 0xX 32-bit; 0xM to 0xT read single bits." %}
d0xH1234
{% trans "The delta: the value the address held on the previous frame." %}
_
{% trans "Joins conditions: all of them must be true on the same frame." %}
S
{% trans "Starts an alternative group: the core conditions plus any one group must be true." %}
R: P:
{% trans "Flags before a condition: ResetIf clears every hit count when it is true, PauseIf suspends the check while it is true." %}
.10.
{% trans "A hit count after a condition: it must be true on that many frames before it counts." %}

{% trans "For example, this condition fires on the frame the byte at 0x61998 changes from 0 to 1:" %}

0xH61998=1_d0xH61998=0

{% include "components/section-heading.html" with title=_("Good practices") %}
  • {% trans "Describe the moment something happens, not a state: compare the value with its delta, as in the example above. A plain comparison can be true for a frame while the game boots and unlock the achievement on load." %}
  • {% trans "Console memory is zeroed at reset, so a 0 often means the game is not running yet. Guard the condition with a value that is only non-zero during play, such as a pointer." %}
  • {% trans "The emulator holds back an achievement whose condition is already true when the game loads. Test from a save state made before the moment it should fire." %}
  • {% trans "Check each address you rely on: code notes describe what the community found, often on another region of the game." %}
  • {% trans "Every save keeps a revision. The History link on the game page shows them, and the author or staff can revert to one." %}
